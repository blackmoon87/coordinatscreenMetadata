## 1. خارطة المنافسين الحاليين في السوق

ينقسم المنافسون في سوق التعرف على الوجوه إلى 4 فئات:

1. **عمالقة السحابة (Cloud Giants)**: AWS Rekognition / Azure Face API
2. **المنصات العالمية المتخصصة**: Face++ / PimEyes / Cognitec
3. **مصنعو العتاد والأجهزة (Hardware Vendors)**: Hikvision / Dahua / ZKTeco
4. **المكتبات مفتوحة المصدر**: InsightFace / DeepFace

## 5. نقاط التفوق الأربع لـ `faceR`

### 1️⃣ سرعة التدريب والتعديل (ArrowClassifier)
المنافسون يحتاجون دقائق/ساعات + GPUs لإضافة شخص جديد. `faceR` يضيف ويتعلم في **0.12 ثانية على CPU عادي**.

### 2️⃣ السيادة على البيانات والسياسات المحلية (Data Sovereignty)
القوانين الحكومية في الشرق الأوسط تمنع رفع صور الوجوه لسيرفرات خارجية. `faceR` يعمل **داخل مقر العميل بالكامل (On-Premises)**.

### 3️⃣ كسر أسعار الاستعلام السحابي (Disruptive Pricing)
شركة بـ 500 موظف تدفع $1,500 - $3,000 شهرياً مع AWS. مع `faceR` تدفع **$199 - $399 شهرياً** فقط (وفر 70%-80%).

### 4️⃣ المرونة والاستغناء عن الأجهزة الخاصة
يعمل مع **أي كاميرا مراقبة قديمة أو جديدة (IP Camera / CCTV / Webcam)** دون الحاجة لشراء أجهزة خاصة.
